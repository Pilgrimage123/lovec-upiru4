# 2. Pravidla Chladnutí výzbroje, mechanika Švunk a čistý start bitev

Sjednotili jsme životní cyklus Chladnutí taktických destiček a manévru Krok do nepřítele: hodnota Chladnutí udává přesný počet následných plných tahů hráče, po které je akce zablokována, a každá nová bitva v rámci výpravy začíná s plně vychladlou výzbrojí (Chladnutí = 0). Původní nefunkční zkracování mezi boji bylo nahrazeno mechanikou **Švunk**, která při usmrcení nepřítele kombem kdykoliv během bitvy zkrátí Chladnutí první (otevírací) destičce právě zahraného komba o počet destiček v něm zařazených. Rozhodli jsme se tak proto, aby hráč mohl do každého střetu vstupovat s plnou taktickou paletou možností a aby zřetězení akcí v kombech přirozeně odměňovalo chytré načasování smrtících úderů znovupoužitelností klíčových otvíráků.
